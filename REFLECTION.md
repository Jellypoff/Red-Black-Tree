Pool 
Geometry. rbnode_t is 48 bytes. The slab header is one 8-byte link, but its offset is rounded up to 16, so a 4096-byte slab has hdr_off = 16, stride = 48, and (4096 - 16) / 48 = 85 slots with 0 bytes of slack (16 + 85 * 48 = 4096). The header costs no slot here, since 4096 / 48 also gives 85. test_geometry pins this row and others. The table static_asserts x86-64.
Alignment. A = alignof(max_align_t) = 16. rb_malloc returns malloc-aligned blocks, and hdr_off and the stride are both rounded up to a multiple of A, so every slot address is a multiple of 16. That covers the node and the 8-byte free-list link in a dead slot. A slot is never smaller than a pointer, so pool_create(1) has stride 16. Slabs are not 4096-aligned, so a slot's slab is never found by masking, nothing needs it.
Header placement: in-band. One rb_malloc per slab means slab growth has a single failure point, so the fault sweep has one fewer unwind path. Out-of-band would have kept the arithmetic cleaner but added a second allocation to unwind.

pool_stats
free_objs = free-list length + slots not yet carved from the newest slab. live + free_objs == slabs * objs_per_slab is asserted after every alloc and free in debug builds. The pooled sweep also checks it from the tree's side, plus live == rb_size(t), because neither the sanitizers nor the allocation counter can see a node leaked inside a slab. Carving is a bump pointer and the first slab is grown lazily and pool_create makes one allocation.

Poisoning
ASan sees a slab as one live 4096-byte block, so a stale pointer into a dead slot looks valid. In debug builds freelist_push fills the whole stride with 0xDD and then writes the link over the first 8 bytes. The link owns those bytes and the poison owns the rest, the other order would destroy the list. A stale reader sees 0xDD, or a pool pointer in the link, instead of old node data. Two checks can turn this into a detector: freelist_pop asserts the bytes past the link are still 0xDD, and pool_free asserts live > 0 and obj != free-list head. Three fork() death tests check that each assert fires.
